문서 중복·유사성 검사기 기본판 — 검증 메모

기준: document_finder_v15.zip
변경 범위:
1) 파일 2개 비교 단계 기반 진행률 표시
2) 줄 단위 전체 색칠 대신 문자 단위 상세 diff
3) 변경된 줄바꿈은 ↵로 가시화
4) A/B 직접 비교에서는 저장된 공백/줄바꿈을 실제 차이로 판정

보존 확인:
- HWP 5.x / HWPX / DOCX / TXT
- 폴더 검사 후보 축소 구조
- 완전 동일 / 내용 동일 / 유사 / 읽기 실패 필터
- CSV 저장
- 폴더 결과 → A/B 비교 전달
- pair_compare_seq stale worker 방지
- A/B 범례 및 스크롤 구조
- 원본 파일 수정/삭제/이동 기능 없음

로컬 검증:
- Python 문법 검사 통과
- Tk UI 생성 smoke test 통과
- CRLF/LF 정규화 확인
- 공백 추가 / 줄바꿈 위치 변경 / 실제 문구 변경 문자 diff 확인
- ZIP 무결성 검사
