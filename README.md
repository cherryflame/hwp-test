# 문서 중복·유사성 검사기 v1.0

Windows에서 HWP 5.x / HWPX / DOCX / TXT / EPUB 문서를 한꺼번에 검사해 중복본·수정본·유사 문서를 찾고, 두 파일의 변경 내용을 나란히 비교하는 도구입니다.

- 원본 파일을 삭제·이동·수정하지 않습니다.
- 폴더 하나 안에서도 서로 다른 형식의 문서를 교차 비교합니다.
- 폴더 검사 결과에서 두 파일을 선택해 상세 비교로 바로 넘길 수 있습니다.
- 구형 Word `.doc`는 지원하지 않습니다.

## 결과 판정

- **완전 동일**: 파일 자체가 동일합니다.
- **내용 동일**: 파일은 다르지만 추출한 본문이 동일합니다.
- **유사**: 같은 원고의 수정본·변형본으로 볼 수 있을 정도로 내용이 유사합니다.
- **유사 100%**가 표시될 수 있습니다. 폴더 검색용 유사도에서는 사실상 동일하게 잡히지만, 단어 몇 개·공백·줄바꿈 등의 차이가 남아 상세 비교에서는 100% 미만으로 나올 수 있습니다.

## 상세 비교 색상

- 빨강: A에만 있는 내용
- 초록: B에만 있는 내용
- 노랑: 양쪽에서 변경된 내용
- 하늘색: 대응되는 내용 안에서 공백·탭·줄바꿈만 다른 부분

A 또는 B에만 있는 블록은 그 안의 공백·줄바꿈도 해당 블록 색상으로 표시합니다. 서로 크게 다른 문장·문단은 음절 단위로 억지 매칭하지 않고 변경 블록으로 처리합니다.

## 비교 시 참고

이 도구는 두 문서의 내용이 대체로 같은 순서로 이어진다는 것을 기준으로 비교합니다. 문장이나 문단 자체를 앞뒤로 이동한 경우에는 이동한 동일 문장을 추적하지 못하고, 한쪽에서 삭제되고 다른 쪽에 추가된 것처럼 표시될 수 있습니다. 문장·문단 순서를 변경한 원고의 색상 표시는 참고용으로 확인해 주세요.

자세한 사용 순서는 `사용가이드.md`를 참고하세요.
