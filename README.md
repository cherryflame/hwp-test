# 문서 중복·유사성 검사기 — 기본판

Windows용 문서 중복·유사성 검사기입니다.

지원 형식: HWP 5.x / HWPX / DOCX / TXT

## 주요 기능
- 폴더 내 완전 동일 / 내용 동일 / 유사 문서 탐색
- 결과 필터 및 CSV 저장
- 두 파일 A/B 직접 비교
- A/B 비교에서 실제 변경 문자·공백만 색상 표시
- 변경된 줄바꿈은 `↵` 기호와 색상으로 위치 표시
- A/B 비교 단계 기반 진행률(%) 및 현재 작업 표시
- 원본 파일 삭제·이동·수정 없음

## 차이 표시
- 빨강: A에만 있음
- 초록: B에만 있음
- 노랑: 양쪽 내용 변경
- 저장된 줄바꿈과 띄어쓰기는 A/B 직접 비교에서 실제 차이로 취급합니다.
- CRLF와 LF처럼 운영체제 개행 코드만 다른 경우는 같은 줄바꿈으로 취급합니다.

## 실행
GitHub Actions에서 Windows EXE로 빌드합니다. Python을 별도로 설치할 필요가 없습니다.
