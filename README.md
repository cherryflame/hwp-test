# 문서 중복·유사성 검사기 — EPUB 지원판 v31

## 지원 형식
HWP 5.x / HWPX / DOCX / TXT / EPUB

## v29 재구축 원칙
- 파일 형식 차이는 텍스트 추출 단계에서만 처리합니다.
- 폴더 검사는 v23의 9글자 shingle 후보망을 유지합니다.
- 형식 공통 semantic fingerprint는 모든 조합을 만들지 않고 문서별 상위 6개 후보만 보강합니다.
- 보강 후보에는 장문 전체 SequenceMatcher를 사용하지 않습니다.
- 상세 비교는 원문을 보존하고 공통 본문 재동기화 + 짧은 차이 구간만 비교합니다.
- 공통 공백/줄바꿈은 무색, 한쪽에 더 있는 공백/줄바꿈만 하늘색입니다.
- A에만 있는 문자/문장부호는 빨강, B에만 있으면 초록, 실제 치환은 노랑입니다.
- 원본 파일을 삭제/이동/수정하지 않습니다.

## 성능 보호
공통 fingerprint 보강 후보는 문서당 최대 6개입니다. 지나치게 흔한 fingerprint는 후보 생성에서 제외합니다. 진행 상태에 기존 후보/보강 후보 수를 표시합니다.

## 참고
구형 Word .doc는 지원하지 않습니다. 아이콘은 기능 검증 완료 후 원본 PNG로 최종 교체하는 것을 전제로 이번 판에서는 재가공하지 않았습니다.

## v30 유사도 산식 수정
- v29 후보 탐색/대량 검사 구조는 변경하지 않음.
- fingerprint는 후보 탐색/내용 겹침 측정에 사용하고, 최종 폴더 유사도에는 전체 의미문자 길이 비율을 함께 반영함.
- 한쪽에만 문장/내용이 추가·누락된 경우 sampled fingerprint가 100%여도 최종 점수는 분량 차이만큼 내려감.
- `유사` 판정의 내부 점수가 정확히 100%인 경우 내부값은 유지하고 화면/CSV 표시만 최대 99.9%로 표시함.
- 완전 동일/내용 동일 100% 표시는 그대로 유지함.
- 상세 비교 색상 엔진은 이번 버전에서 변경하지 않음.


## v31 상세 비교 블록 판정 수정
- v30의 폴더 검사/후보 탐색/최종 유사도 산식은 변경하지 않음.
- A에만 있는 변경 블록은 공백·줄바꿈까지 포함해 전체 빨강으로 표시.
- B에만 있는 변경 블록은 공백·줄바꿈까지 포함해 전체 초록으로 표시.
- 양쪽에 내용이 있으나 충분히 긴 저유사도 블록은 내부 음절을 억지로 맞추지 않고 블록 전체를 노랑(양쪽 내용 변경)으로 표시.
- 서로 충분히 비슷한 부분 수정 블록은 기존 문자/공백 상세 비교를 유지.
- 순수 공백·탭·줄바꿈 차이는 기존 하늘색 표시 유지.
