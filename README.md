# 문서 중복·유사성 검사기 — EPUB 교차검증 테스트판 (v28-1)

확정 v23 기본판에서 다시 분기한 **교차검증 전용 중간 테스트판**입니다. 상세 비교 색상 엔진은 아직 교체하지 않았습니다.

## 지원 형식
- HWP 5.x
- HWPX
- DOCX
- TXT
- EPUB

※ 구형 Microsoft Word `.doc` 바이너리 형식은 현재 지원하지 않습니다. `.docx`만 지원합니다.

## v28-1의 검증 목적
- 폴더 1개 또는 여러 폴더에서 모든 지원 형식을 서로 교차 후보화
- HWP ↔ HWPX ↔ DOCX ↔ TXT ↔ EPUB 조합을 형식 구분 없이 탐색
- 전수 O(n²) 정밀비교 대신 v23 역색인 + content-defined fingerprint 역색인을 병행
- 줄바꿈·공백·문단 장식 차이 때문에 TXT/EPUB 등이 후보 단계에서 누락되는 문제 완화
- 서로 다른 형식의 최종 유사도는 공백·문단 장식에 덜 민감한 공통 fingerprint를 사용

## 아직 하지 않은 것
- 상세 비교의 빨강/초록/노랑/파랑 판정 재설계
- A/B 상세 비교 재동기화 엔진 교체

교차검증이 실제 문서 세트에서 안정적으로 작동하는지 먼저 확인한 뒤 상세 비교 색상 엔진을 별도 단계로 수정합니다.
