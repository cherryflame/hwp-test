# 문서 중복·유사성 검사기 — EPUB 지원판 v28-2

v28-1의 전체 교차형식 폴더 검사를 유지하고, 파일 2개 상세 비교 엔진을 교체한 테스트판입니다.

## 지원 형식
HWP 5.x / HWPX / DOCX / TXT / EPUB

## v28-2 변경
- 서로 다른 형식의 A/B 유사도는 폴더 검사와 같은 content-defined fingerprint 기준 사용
- EPUB/TXT 등 교차형식 장문에서 전체 SequenceMatcher를 사용하지 않음
- 의미 문자 앵커로 약 260자 간격 재동기화 후 작은 구간만 상세 diff
- 공백/탭/엔터 차이: 파랑, 공백 `·`, 탭 `→`, 엔터 `↵`
- A에만 있는 문자/문장부호: 빨강
- B에만 있는 문자/문장부호: 초록
- 실제 문자 치환: 노랑
- 마침표+줄바꿈 삭제 뒤에도 다음 동일 본문에서 재동기화
- 같은 형식 문서는 v23 줄 정렬 경로를 유지하되 변경 블록 내부만 세부 분류

※ 구형 Word `.doc` 바이너리 형식은 지원하지 않습니다.
