## v28-3 변경
- 폴더 검사: v23의 9글자 shingle 역색인을 주 경로로 유지합니다.
- 공통 fingerprint 보조 후보망은 서로 다른 확장자 조합에만 사용합니다.
- 한 fingerprint가 36개 초과 문서에 나타나면 식별력이 낮은 공통 토큰으로 보고 보조 후보 생성에서 제외합니다.
- 같은 형식끼리는 새 fingerprint 후보망을 추가하지 않아 대량 폴더의 후보 폭증을 억제합니다.
- 상세 비교: 공백/줄바꿈 run 내부의 공통 부분은 무색으로 상쇄합니다.
  - A ↵↵ / B ↵↵↵ → 공통 ↵↵ 무색, B의 추가 ↵ 하나만 하늘색
  - A `..↵` / B `↵` → `..`만 A에만 있음(빨강), 공통 ↵ 무색
- A에만 있음=빨강, B에만 있음=초록, 실제 치환=노랑, 남는 공백·줄바꿈 차이=하늘색 규칙 유지.
