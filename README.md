# 문서 중복·유사성 검사기

Windows에서 HWP 5.x / HWPX / DOCX / TXT 문서의 중복·유사본을 찾고,
파일 두 개의 본문 차이를 비교하는 읽기 전용 로컬 프로그램입니다.

## 주요 기능
- 여러 폴더 재귀 검사
- 완전 동일 / 내용 동일 / 유사 / 읽기 실패 분류
- 결과 필터 및 CSV 저장
- HWP 5.x / HWPX / DOCX / TXT 지원
- 서로 다른 형식끼리 본문 비교 가능
- A/B 좌우 비교
  - 빨강: A에만 있음
  - 초록: B에만 있음
  - 노랑: 실제 문구가 달라진 줄/변경 블록
  - 파랑: 글자는 같고 공백·줄바꿈만 다른 위치 (`·`, `↵`로 표시)
- 파일 2개 비교 단계별 진행률 표시
- 폴더 검사 결과에서 파일 두 개를 선택해 비교 탭으로 전달
- 원본 파일 삭제·이동·수정 없음

## 비교 방식
기본 구조는 v15의 줄 단위 비교를 유지합니다. 실제 문구가 달라진 경우에는 기존처럼 줄/변경 블록 단위로 표시합니다.
공백·줄바꿈만 다른 구간은 문자 단위 SequenceMatcher를 사용하지 않고 선형으로 위치를 확인하여 파란색으로 표시합니다.
문서 전체가 공백·줄바꿈만 다른 경우에는 줄 단위 SequenceMatcher도 생략합니다.

## 빌드
GitHub 저장소 최상위에 이 ZIP의 내용을 그대로 올린 뒤
`Actions → Build Windows EXE → Run workflow`를 실행합니다.

artifact `문서_중복_유사성_검사기_Windows`에서
`문서_중복_유사성_검사기.exe`를 받을 수 있습니다.
사용자 PC에는 Python 설치가 필요하지 않습니다.
