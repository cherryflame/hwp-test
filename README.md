# 문서 중복·유사성 검사기 — 최종판 준비본

Windows 로컬에서 HWP 5.x / HWPX / DOCX / TXT 문서를 비교하는 읽기 전용 도구입니다.

## 현재 반영
- 프로그램명에서 `백업`, `v4` 등 개발용 명칭 제거
- EXE 출력명: `문서_중복_유사성_검사기.exe`
- 폴더 중복 검사 / 파일 2개 비교
- 결과 필터 버튼: 전체 / 완전 동일 / 내용 동일 / 유사 / 읽기 실패
- `전체` 숫자를 각 필터 항목 수의 합으로 계산하도록 수정
- 세로/가로 결과 스크롤바
- 동일 파일 조합 중복 출력 제거
- 일부 오래된 문서의 비정상 Unicode surrogate 때문에 UTF-8 encode 단계가 실패하지 않도록 방어 처리
- 원본 파일 삭제/이동/수정 없음

## 아직 의도적으로 미적용
- 최종 전용 아이콘: 사용자에게 시안을 먼저 확인받은 뒤 적용 예정.

## 확인할 것
기존에 `UTF-8 codec can't encode characters...` 오류가 난 파일을 다시 검사해 읽기 실패가 사라지는지 확인합니다.
만약 계속 실패하면 해당 오류 문구 또는 문제 파일 1개를 기준으로 HWP 추출 라이브러리 내부 단계까지 확인해야 합니다.

GitHub Actions → `Build Windows EXE` → `Run workflow` 후 artifact에서 EXE를 받습니다.

## 이번 수정
- 폴더 검사 결과의 `선택한 두 파일 차이 보기`에서 개발자식 unified diff 별도 창 제거
- 선택 파일 A/B를 `파일 2개 비교` 탭으로 전달
- 탭 자동 이동 후 기존 좌우 비교 UI에서 즉시 비교
- 최초 사용 시 기존 비교 결과가 교체된다는 안내창 표시
- `이번 실행 중에는 다시 보지 않기` 지원
- 프로그램을 종료했다 다시 실행하면 안내창은 다시 표시
- 이미 진행 중인 비교가 있을 때 중복 비교 시작 방지
- 오래 걸린 이전 비교 결과가 새 비교 화면을 뒤늦게 덮어쓰지 않도록 순번 보호
