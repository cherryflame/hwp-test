# 문서 중복·유사성 검사기 — EPUB 지원판

Windows에서 HWP 5.x / HWPX / DOCX / TXT / EPUB 문서의 중복·유사본을 찾고,
파일 두 개의 본문 차이를 비교하는 읽기 전용 로컬 프로그램입니다.

## 주요 기능
- 여러 폴더 재귀 검사
- 완전 동일 / 내용 동일 / 유사 / 읽기 실패 분류
- 결과 필터 및 CSV 저장
- HWP 5.x / HWPX / DOCX / TXT / EPUB 지원
- 서로 다른 형식끼리 본문 비교 가능
- A/B 좌우 비교 및 차이 색상 표시
  - 빨강: A에만 있음
  - 초록: B에만 있음
  - 노랑: 양쪽 내용 변경
- 폴더 검사 결과에서 파일 두 개를 선택해 비교 탭으로 전달
- 원본 파일 삭제·이동·수정 없음

## 빌드
GitHub 저장소 최상위에 이 ZIP의 내용을 그대로 올린 뒤
`Actions → Build Windows EXE → Run workflow`를 실행합니다.

artifact `문서_중복_유사성_검사기_Windows`에서
`문서_중복_유사성_검사기.exe`를 받을 수 있습니다.
사용자 PC에는 Python 설치가 필요하지 않습니다.

## 아이콘
- `app.ico`: EXE/Windows 아이콘
- `app_icon_16.png`, `app_icon_32.png`, `app_icon_48.png`, `app_icon_64.png`:
  실행 중 창/작업표시줄 아이콘
- 빌드 후 EXE 내부 RT_ICON / RT_GROUP_ICON 리소스를 자동 검증합니다.
- 같은 이름의 EXE를 반복 빌드한 뒤 탐색기에서 이전 아이콘이 보이면
  Windows 아이콘 캐시일 수 있습니다. 실제 최종 테스트에서는 파일명을 바꾸자 정상 표시되었습니다.

## 최종 확인
- Windows 실사용 정상
- 폴더 중복 검사 정상
- 파일 2개 비교 정상
- 비교 색상 범례 정상
- 보조 버튼 1px 테두리 정상
- 중요 버튼 남색 강조 정상
- 실행창/작업표시줄 아이콘 정상
- 탐색기 아이콘은 파일명 변경 후 정상 표시

## EPUB 지원

- EPUB의 `META-INF/container.xml`에서 OPF를 찾고, OPF의 `spine` 읽기 순서대로 XHTML/HTML 본문을 추출합니다.
- 표지 이미지·CSS 등 비본문 리소스는 비교 대상에서 제외합니다.
- EPUB ↔ EPUB뿐 아니라 EPUB ↔ HWP/HWPX/DOCX/TXT 교차 비교를 지원합니다.
- EPUB과 원고 파일은 서식 표현 차이가 있을 수 있으므로 파일 자체가 달라도 본문 유사도 기준으로 판정할 수 있습니다.


## 버전 표시

- 프로그램 창 제목과 상단 제목에 `문서 중복·유사성 검사기 — EPUB 지원판`을 표시합니다.
- EXE 파일명은 기존 배포/빌드 흐름과의 호환을 위해 `문서_중복_유사성_검사기.exe`를 유지합니다.
